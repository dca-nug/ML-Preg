#  WHY THE FLOORS SIT WHERE THEY DO
#  --------------------------------
#  The APIs this code calls are old. `spearmanr(...).statistic` needs scipy
#  1.9, `CalibratedClassifierCV.estimator` needs scikit-learn 1.2, and dropping
#  `use_label_encoder` needs xgboost 2.0. Those floors are not the binding
#  constraint.
#
#  imbalanced-learn 0.14 is. Its own metadata requires numpy>=1.25.2,
#  scipy>=1.11.4, scikit-learn>=1.4.2, and Python>=3.10, so an environment
#  built to the API floors above would not resolve. The floors below are set by
#  imbalanced-learn where it binds and by the API elsewhere.
#
#  Python 3.10 or later. The reported run used 3.11.4.
#
# -----------------------------------------------------------------------------
#  Core numerical stack
# -----------------------------------------------------------------------------
numpy>=1.25.2            # floor set by imbalanced-learn 0.14

                         # (the API needs only 1.9, for spearmanr(...).statistic)

# -----------------------------------------------------------------------------
#  Learners
